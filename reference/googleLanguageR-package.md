# googleLanguageR

This package contains functions for analysing language through the
Google Cloud Machine Learning APIs

## Details

For examples and documentation see the vignettes and the website:

<https://github.com/ropensci/googleLanguageR>

## See also

<https://cloud.google.com/products/machine-learning>

googleLanguageR: Interface to Google Cloud NLP, Translation, and Speech
APIs

A package for interacting with Google Cloud's language APIs from R.
